# 🌍 TourPulse Udaipur
### Tourism Intelligence Dashboard | SQL Server • Power BI • Excel


---

## 📌 Project Overview

TourPulse Udaipur is a Tourism Intelligence Dashboard designed to analyze tourist attractions, hotel performance, visitor reviews, and travel recommendations across Udaipur.

The project combines data engineering, SQL database design, business intelligence, and analytics to help tourists discover the best attractions and accommodation options.

---

## 🎯 Business Problem

Tourists often struggle to:

- Identify the most popular attractions
- Find suitable hotels near attractions
- Compare hotel pricing and ratings
- Understand seasonal tourism trends
- Analyze visitor sentiment from reviews

This dashboard solves these challenges through interactive visual analytics.

## 🗄 Database Schema

The project uses a relational database consisting of:

### Attractions
Tourist attraction information

### Hotels
Hotel details, ratings, pricing, categories

### Reviews
Hotel and attraction review sentiment

### Hotel Attraction Mapping
Links hotels with nearby attractions

### Seasonality
Tourism trends across months
